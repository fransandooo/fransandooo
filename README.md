      <p>
        Recognises isolated American Sign Language words from video using only 3D hand landmarks
        (MediaPipe), with a <b>BiGRU + temporal attention</b> model (2.26 M params). The input
        is ~2,389× smaller than raw pixels.
      </p>

        <li><b>63.9 % Top-1 / 86.5 % Top-5</b> on WLASL30 (stratified 5-fold CV)</li>
        <li><b>70.2 % Top-1 / 90.5 % Top-5</b> on MS-ASL50 with no re-tuning (3 seeds)</li>
        <li>Architecture study (LSTM, GRU, Transformer), sequence-length sweep, vocabulary scaling up to 1,500 words</li>
        <li>End-to-end prototype: Expo mobile app + FastAPI inference server, tested with 15 users</li>
